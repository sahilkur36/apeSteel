# apeSteel

Composition-based, strictly-typed steel-design library for the AISC standards.

!!! info "Pre-alpha"
    This page is the stub for the documentation site. Content is being filled in.

## Coverage

- **AISC 360-22** — Member design (Chapters B, D, E, F, G, H)
- **AISC 341-22** — Seismic provisions
- **AISC 358-22** — Prequalified moment connections
- **EN 10365** — IPE / HE European shapes (catalog only)
